# Decision notes

One short file per decision that later work depends on: `NNNN-short-title.md`.

```
# NNNN Title
Date: YYYY-MM-DD   Path: <path>   Status: accepted | superseded by NNNN
Context: what forced a choice (two or three lines)
Decision: what was chosen
Why: evidence, with links to results/
Consequences: what this rules in or out
```
